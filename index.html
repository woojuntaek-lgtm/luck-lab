🐍 스트림릿으로 만드는 대시보드

# app.py → 터미널에서: streamlit run app.py import streamlit as st, plotly.express as px, numpy as np x = np.random.default_rng(3).lognormal(10, 0.6, 1000) k = st.sidebar.slider('IQR 배수', 1.0, 3.5, 1.5, 0.1) # 최솟값, 최댓값, 기본값, 간격 q1, q3 = np.percentile(x, [25, 75]); iqr = q3 - q1 out = (x < q1 - k*iqr) | (x > q3 + k*iqr) c1, c2 = st.columns(2) c1.metric('기준 배수', k) # 큰 카드 숫자 c2.metric('이상치 개수', int(out.sum())) st.plotly_chart(px.histogram(x[~out], nbins=40)) # 확대·마우스 올리기 # 슬라이더를 움직일 때마다 스크립트 전체가 다시 실행됨

📌 세 줄 정리

  1. 주제는 가치와 데이터 가용성으로 고르고, 목표는 SMART하게, 가설은 확인할 수 있게 쓴다.
  2. p값은 우연의 확률이고, 스무 번 검정하면 하나쯤은 우연히 걸리니 계획을 먼저 적고 보정한다.
