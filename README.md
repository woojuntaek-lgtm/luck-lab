# 우연 당첨 연구소

효과가 없는데 아홉 번째 무리만 유의하다? — 하나의 탐색 프로젝트를 완성하는 과정을 손으로 체험하는 앱입니다. 쿠폰 효과가 0인 무리 20개를 t검정하는 첫 장면(9번 무리 p = 0.0136, 본페로니 기준 0.0025), 퀴즈 ①(약 64%), 효과 0인 데이터로 직접 돌리는 모의실험, 검정 횟수에 따른 오류 확률 곡선, SMART 목표 점검, 확인할 수 있는 가설과 귀무·대립가설, t분포 꼬리 넓이로 보는 p값, 흔한 오해 세 가지, 데이터 명세서, AARRR 퍼널과 퀴즈 ②(500명), 코호트 히트맵, 전략형·분석형·운영형 대시보드, IQR 배수 슬라이더(38·24·10개), 스트림릿 코드까지 담았습니다. 빅데이터 13 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 스무 번: 첫 장면, 퀴즈 ①, 모의실험, 검정 횟수 곡선
- ② 가설·p값: SMART 목표, 가설, p값 그림, 흔한 오해
- ③ 퍼널·코호트: 탐색 계획서와 데이터 명세서, 퍼널, 퀴즈 ②, 코호트
- ④ 대시보드: 대시보드 세 유형, 이상치 기준 슬라이더, 스트림릿 코드, 세 줄 정리, 생각해 볼 질문

t검정(불완전 베타 함수로 t분포 계산)과 모의실험은 브라우저에서 직접 계산합니다. 무리 20개의 구매액 2,000개와 소득 모양 데이터 1,000개는 원고 메모의 방식(numpy default_rng(9), default_rng(3))으로 만든 모의 데이터를 그대로 담았습니다. 코호트 잔존율은 원고의 설명용 예시 값이고, 대시보드 화면의 숫자는 가상입니다.
